TangleLens

IOTA Advanced Explorer for Eclipse aeriOS: searchable, continuously verified, on the real Hornet node

The problem

  • aeriOS trust data is hex behind 32-byte block ids
  • No search by tag, date or sender
  • No proof a message is on the ledger, final and unchanged

What we built

  • Extended Messages API: same /upload contract; forwards block id + exact bytes (HTTP and MQTT)
  • Explorer: PostgreSQL copy with readable metadata; search by block id, date, tag
  • Verification: solidity via GET block metadata, content via GET block

github.com/moe-a-m/tanglelens · Apache-2.0 · Docker Compose · runs on the aeriOS private tangle (HORNET 2.0.2)

TangleLens is the IOTA Advanced Explorer the challenge asks for. The Tangle is authoritative but opaque; we built the two required applications: the extended aeriOS Messages API, which forwards every accepted block with its exact bytes, and the explorer, which stores a readable, searchable copy and verifies each block against Hornet.
