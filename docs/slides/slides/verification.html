Content check, three levels

  1. Exact hex bytes
  2. Decoded JSON
  3. SHA-256 fingerprint

Editing either the raw or the readable copy in the database is caught. Every check is appended to an audit trail; all messages are re-audited every 5 minutes.

A block is solid almost immediately, but it is only final when a milestone references it, so we report those separately. Problem states are in red; content mismatch takes precedence over everything. The content check compares at three levels, so tampering with either the hex or the human-readable copy is detected. Every check is kept in an audit trail, never overwritten.
