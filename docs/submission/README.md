# TAIKAI submission

- `TangleLens_VelesHack_Submission.pdf`: the presentation attached to the TAIKAI project (organizers' template: cover + GitHub repo, Summary, Highlights).
- `TangleLens_VelesHack_Submission.pptx`: the same deck, editable.
- `fill_template.py`: rebuilds the deck from the organizers' template (kept locally in `template/`, not redistributed) and `docs/screenshots/`:
  `python -I fill_template.py template/VelesHack_ProjectSubmissionTemplate.pptx ../screenshots TangleLens_VelesHack_Submission.pptx` (needs python-pptx 1.0.2).

The 14-slide deck for the Thursday final is in `docs/slides/`.
